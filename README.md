# Sistema de Gerenciamento de Chamados de TI

## Sobre o projeto
Desenvolvi este projeto em Python para praticar os conceitos básicos de programação em uma situação comum no suporte técnico de empresas.

Minha ideia foi simular um sistema de Help Desk, no qual usuários podem registrar problemas técnicos e acompanhar o andamento dos chamados.

## Funcionalidades
- Abrir chamados de suporte técnico.
- Cadastrar o nome do solicitante e a descrição do problema.
- Definir a prioridade dos chamados.
- Consultar chamados pelo número de identificação.
- Atualizar o status dos chamados.
- Excluir chamados.
- Gerar relatórios com a quantidade de chamados por situação.

## Conhecimentos utilizados
Python, listas, estruturas condicionais (`if`, `elif`, `else`), estruturas de repetição (`while`, `for`) e manipulação de dados.

## Como executar
Execute o arquivo Python do projeto em um ambiente com Python 3 instalado.

**Observação:** Projeto acadêmico que simula operações básicas de um sistema de suporte técnico. Os registros não são armazenados permanentemente.
